### Step 2.3: Payment Processing

**What Thabo sees:**
- Paystack loading spinner
- OTP verification (if required by bank)
- "Processing payment..." message

**Behind the scenes:**
1. Paystack processes payment
2. Paystack sends webhook to `/api/webhooks/paystack`
3. Webhook updates order status to "completed"
4. Webhook grants access to: starter-kit, niche-finder, paids-workbook, influencers-code
5. Webhook sends confirmation email
6. Paystack redirects to success page

## ERROR SCENARIOS & HANDLING

### Scenario A: Payment Fails
- User sees Paystack error message
- Order is rolled back (deleted from database)
- User can retry with different payment method

### Scenario B: User Enters Wrong Email at Checkout
- Confirmation email goes to wrong address
- User can contact support
- Admin can update customer_access email

### Scenario C: Verification Code Expired
- User sees: "Code expired. Please request a new one."
- Can click "Use different email" or request new code

### Scenario D: User Forgets Email Used
- Support can look up by name
- User can try different emails
